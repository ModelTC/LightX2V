# Platform validation

The NVIDIA A100 campaign includes native comparison and process/resource evidence. MLU590 has a single-card LightX2V campaign that calls pinned inference PR #1753 across all 1,023 GSO objects and computes geometry quality and latency. It records the assigned physical card and MLU peak allocated memory; it does not implement native comparison or host-visible process attribution, so it cannot establish A100 parity or resource-isolated latency. MLU results must be reported as MLU-only measurements. MetaX and Ascend NPU remain placeholders.

Submit only this evaluation directory. Exclude history/, artifacts/, cache/, runtime/, sources/, data/, WORK_LOG.md and all local paths. Before submission inspect the actual git diff and GitHub PR file list. Put sanitized proven summaries under results/nvidia; record source/evaluator hashes, full coverage, failures, quality metrics, end-to-end distribution, native ratios, GPU UUID and evidence archive hashes. Never describe a partial smoke test as a complete campaign.
