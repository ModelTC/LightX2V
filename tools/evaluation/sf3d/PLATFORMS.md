# Platform validation

The NVIDIA A100 campaign is the only complete evaluation implementation. MLU590 has a one-input functional smoke entry that calls pinned inference PR #1753 and checks a geometry-only GLB. It does not implement native comparison, quality scoring, latency measurement, resource capture, or a complete-dataset campaign. Do not report it as platform validation. A future campaign needs native runtime parity, MLU synchronization/seed/memory APIs, host-visible process attribution, dependency/source locks, and complete single-device evidence. MetaX and Ascend NPU remain placeholders.

Submit only this evaluation directory. Exclude history/, artifacts/, cache/, runtime/, sources/, data/, WORK_LOG.md and all local paths. Before submission inspect the actual git diff and GitHub PR file list. Put sanitized proven summaries under results/nvidia; record source/evaluator hashes, full coverage, failures, quality metrics, end-to-end distribution, native ratios, GPU UUID and evidence archive hashes. Never describe a partial smoke test as a complete campaign.
