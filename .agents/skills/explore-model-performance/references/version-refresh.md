# 项目与依赖变化后的知识核验

在探索启动、恢复、继续已有任务、复用历史支持/性能判断或运行环境改变时执行。记录到当前唯一工作包，沿用已有事实产物，不另建公共状态schema。实验内冻结版本；采用变化后的环境另立批次，旧证据不改写。

首次核验没有相关历史时，记录当前身份、来源及必要基线，明确“首次/无记录”；仅对实际复用的旧知识核其相应历史身份，不要求先存在上次任务。

## 发现与定位

1. 核实际LightX2V HEAD、未提交/未跟踪差异、模型/配置；相关依赖检查实际安装版本/来源commit（可得时）、必要关键加载文件/扩展或接口事实。相同包版本号不单独证明本地patch/二进制相同。
2. 有相关上次身份时对比当前环境；访问条件和授权允许时主动核可获取的上游main、相关PR及依赖发布/接口变化，注明查询窗口与未覆盖范围。分别记录上游可参考能力、本环境已有能力、实际执行过的能力，不将未合入/未安装能力写为当前可执行，也不为更新知识自动升级运行环境。
3. 先读变更总体的文件/配置/注册概览，再沿相关方法及共享调用链定位影响；不能只看旧地图列出的路径。新增入口补发现，接口/默认/返回值/权重表示变化追到真实消费者；未能裁决的影响标为复用待核，不能默认旧判断仍有效。

固定执行输入时，沿启动与请求构建找到最终覆盖/合并处，区分参数声明、配置意图与实际生效值；配置省略不等于关闭，未读到的checkpoint或外部配置保留未知。比较负载或预热覆盖时，核尺寸对齐、padding等变换后consumer实际收到的shape及状态，不只比较名义参数。优先复用已有运行的有效配置和输入记录；缺事实才补最小追踪，不为核默认值加载整网，也不擅自改配置掩盖未知。

## 按知识性质处理

| 内容 | 动作与证据 |
|---|---|
| 代码导航、方法来源和支持范围 | 找替代实现/实际注册与准入；修正旧路径/限制。源码可确认参考实现，实际kernel支持仍须执行证据。 |
| ABI、shape/精度、mask/LSE、权重和生命周期合同 | 沿producer/consumer核变更；必要时定向调用，不用相同名称或import成功代替。 |
| 历史性能、质量及负结果 | 保留旧条件下的事实；相关条件变化重开适用性判断，按当前成本选必要局部/请求补测。新backend存在不代表更快，旧负结果不永久否决新版本。 |

仅路径/说明变化可源码核验；接口/表示变化做最小调用验证；影响数值/性能再补对应实验。确认未受影响的证据可复用，补测范围按实际变化和任务目标决定。依赖实际升级未验证时明示，源码或模拟检查不冒称真实升级验收。

## 更新并核对结果

在工作包简记“上次/当前身份、相关变化、受影响判断、补证及处置/剩余未知”，引用已有文件。发现变化、阻止直接套用旧判断、补证、修订知识分别有事实，不以“已检查版本”替代后续动作。

成熟修订回所属工具、现有方法地图/指南或接口README并形成可审查增量，随项目继承；本机事实/完整证据留本地。性能/质量结论绑定条件，不覆盖历史值。无相关变化时记核验范围和复用依据即可，不制造文档改动。

这是任务使用时的主动维护；无人运行时的后台同步、全历史/全部PR覆盖和自动发布不在本skill保证内。

## 履约依赖与增量重开

固定本次验收实际使用的源码、配置、输入、父方案、批准、方法库和成本依据的内容身份与作用子项。规则覆盖层与模型源码基线分角色核对；二者不一致时，按当前任务目标和实际调用裁决，记录采用及修订依据，不仅凭文件所在目录或已有绑定认定规则仍有效。新增模型或方法入口触发发现回扫，子项与依赖按本轮实际情况确定，不照搬旧数量或全集。

模型、平台或项目演进导致旧范围、读取器或工具合同不适配时，Agent应在已有授权内主动调整：说明变化及其影响，保留旧版本与原始证据，修订相应范围/适配代码，验证受影响路径后更新消费者绑定及收据。格式或路径迁移不自动否定旧性能事实；是否能复用取决于实际对象、输入、执行条件与结论是否仍相容。仅替换散列不能证明新合同正确，也不应为满足旧检查改造新模型去迎合旧假设。变化本身不要求开发者配合；超出已有目标或授权的取舍才需澄清。

有影响的源码/输入/父方案变化，重开直接及依赖子项的适用性、当前证据和采用判断，历史测量原件保留；成本或方法库变化重评发现与决策。父方案拒绝或输出变化不沿用子组合旧批准，新的批准须绑定实际输出及原始决定。本轮研究验收不支持自动消费正向采用批准：缺少规范原生决定读取器时拒绝 `approved`，仅处理研究/待审/拒绝/重开状态及批准撤回。报告排版/检查器变化只重新验收交付，不自动重做模型实验。确认未受影响的范围继续复用，恢复本身不触发全矩阵。变更检查只给影响清单；显式回写当前唯一工作包后再补最小必要验证。

捕获输入同时核 producer 表示与真实 consumer ABI：包装批次、布局、dtype、设备和状态可能与原生入口不同。内容摘要一致只能证明同一数据，不能证明接线正确；必要转换应保留元素身份及转换依据，无效尝试独立保留。
