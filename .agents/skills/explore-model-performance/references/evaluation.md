# 优化探索的行为核查与工作流评估

用于专门评价探索工作流或改进规则；普通优化按skill正文主动核查，不默认另开评估实验。模型、平台、比较方式和独立性由评估问题决定，不要求存在旧方案。是否新增实测服从当前任务授权。

## 先确定问题和证据

执行前明确评估目标、判断标准、模型/负载、代码/依赖与规范版本、上下文和可见材料、资源预算、停止条件及取证范围。整包记录skill/references、方法库和公共工具的版本与来源；其中通用历史经验可随正式包使用，不为追求独立性机械剥离。只改变部分规范时记录其余工具/资料是否一致；整包表现不归因某一条文字，期间变化须记录影响。

- 无可比历史时，可核本次实际行为、交付和成本是否达到目标，不能虚构净改善。
- 采用已有结果作对照时，冻结实际配置/patch及依赖、统计、证据位置和身份，核输入、版本、平台、测量范围、质量及采用状态，保留不可比项；历史比较不自动成为同期受控试验。补充观测另立身份和成本，不改写旧产物或伪装成旧轮原有记录。
- 需要同期对照时，预先固定共同条件、可变因素、资源及评价口径，再按实际控制强度解释结果，不根据结果临时调整某组规则。
- 需要独立探索时，约定执行者可见资料及上下文历史并记录实际访问/隔离措施；复用材料时记录来源和条件。目录或提示隔离不能消除底层模型先验，指令隔离不冒称硬权限隔离。

已有材料足以回答问题时使用已有证据；缺少会影响判断的证据，才在授权范围内补相应观察。具体比较组、历史结果揭示时点、模型/硬件选择和实验参数留任务计划，不写成所有评估的先决条件。

## 检验独立探索时的条件设计

仅在问题需要检验独立发现/推进能力时采用下列控制；回归、定点核查和给定材料的接续可使用其他设计，明确实际起点即可。

- 若要检验对新任务的适用性，优先用未参与本轮规则打磨的留出任务；使用打磨任务作回归时标记来源和外推限制，不强制更换模型或平台。
- 要求不受该任务既有答案影响时，使用未接触相关探索历史的新上下文。知晓答案者可以组织材料或事后审查，但不能冒称满足该条件的独立执行者，也不能经提示、摘要或脚本传递答案；达不到时据实说明独立性不足。
- 执行者或审查者需保持答案不可见时，资料边界还包括角色通信及工具返回的元数据、状态和终稿摘要；事先核实际可见范围与限制，不承诺工具未提供的硬隔离。工具不能限制答案回流时，优先先冻结需盲性角色的产物，再引入知情比较角色，或明确改为知情审查。意外曝光须记录时点、范围与原结果；曝光前已冻结的结果不受该次后发曝光影响，曝光后的上下文不能以“不使用”恢复盲性。以未接触答案的新上下文重建受影响角色，或明确后续为知情工作；修订结果另记，不将后续协助追溯为此前的独立产物。
- 区分题面资产、正式方法知识与答案材料。检验自主发现时，可提供公共权重、原始输入/配置和工具；避免预供旧候选、诊断、失败分支或已替代关键发现工作的专用接线。需要固定输入回放时可将张量明确作为题面，但说明哪些输入准备/发现已由题面完成，不冒称全链路独立发现。
- 采用历史结果盲化事后对照时，执行前冻结题面、包版本、允许/排除资料、取证及揭示规则，记录标识/hash、来源与实际接收状态；先冻结新轮结论、代码/配置和产物身份，再揭示历史答案。按预定范围和正常停止条件完成新探索，不照抄已知旧路径或因只需结果对照而缩短范围。

## 核实际行动及记录

按风险与影响核关键取舍、条件变化和收口时的证据链，保留简明依据及产物引用：

1. 机会发现：实际pipeline、方法/必要子项与当前代码/依赖能否对账，父项汇总是否掩盖遗漏。
2. 选择与执行：成本依据、预期及父方案是否对应实际命令/调用、输入/配置、完成边界和正常/诊断记录；核是否重复、跳过必要步骤或发生fallback。
3. 观察与调整：正负结果、噪声、质量/资源变化是否对应继续、停止、重排或组合回扫；只改报告措辞不能作为行动改变的证据。
4. 结论与交付：报告、真实结果、质量状态、配置/patch及依赖是否一致，未闭合项是否明确影响哪些结论。

按预定评估范围汇总侦察、试验、复核和修订的完整过程；迭代次数不能代替结果、质量或成本证据。涉及自主性时，分别记录独立产物、外部协助及对应投入。

记录“检查范围—实际动作与证据—偏差/缺口—纠正及结果—剩余限制”。记录缺失与动作未做分别判断；不因一张完整表格就判实际执行通过。发现必要且可执行缺口，在任务授权内补齐；事实已充分时不为检查重复实验。

完整过程成本保存在当前任务记录和已有运行收据：材料准备/接线、加载/编译、测量/诊断、失败恢复、整理/审查、Agent/人工纠偏和等待。[任务总报告](../../../../tools/EXPLORATION_REPORT_TEMPLATE.md)按技术或流程评价目标保留必要汇总和证据入口；日常进度及协作经过在session沟通，不逐条写入模型报告。说明统计边界与并行重叠；未采集写未知，不能从模型加速反推探索效率。历史成本缺失时只报告已观测成本，不报旧新净节省或效率比。

## 按问题组织评价

可从以下维度组织观察；具体指标和分值按任务约定，缺项不填0，不用总分掩盖未知：

| 维度 | 观察与证据 |
|---|---|
| 探索价值 | 机会与必要子项的发现/处置、正负结果、局部/整体候选及实际质量/资源取舍。 |
| 证据可信 | 输入和版本身份、真实路径/父方案、受控比较、未知边界与可重建交付。 |
| 总体效率 | 完整过程成本及其产出、无效重复和额外等待；有可比证据才报告净节省。 |
| 审查负担 | 理解、追溯、重建及纠偏的实际投入；没有人审记录不虚构节省分钟。 |
| 演进适应 | 实际变化的识别、旧判断修正、证据复用/重开与知识回流；无变化时写未观测。 |

## 反馈与解释边界

先区分执行遗漏、工具/接口缺口、资料入口不清和规则不适用，再按维护授权修正、简化或撤回相应内容，保留触发条件、纠正结果及限制。单次执行失误不自动变成新的普遍规则，也不为凑维度新增实验。

实际记录可以支持“做了什么、漏了什么、如何纠正”；若无可比执行证据，不能宣称某条规则导致行为或结果改善。文档/链接检查只证明静态一致性，不能替代实际行为、性能或质量验证；单例不证明普遍有效。主动核查是Agent执行职责，不承诺无人运行时的后台检查或自动强制。
