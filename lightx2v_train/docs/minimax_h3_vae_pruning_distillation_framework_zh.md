# 视频 VAE 剪枝与蒸馏框架

先学习“保留哪些层”，再恢复重建质量。保持原版潜变量接口、时空尺寸和分块融合协议不变。

流程图使用普通文本代码块，按等宽字体显示，无需 Mermaid。

## 1. 总体流程

```text
┌────────────────────────────────────┐
│              原始 VAE              │
│           保留潜变量接口           │
└────────────────────────────────────┘
                   │
                   ▼
┌────────────────────────────────────┐
│          阶段一：结构搜索          │
│       只训练门控 + 临时 LoRA       │
└────────────────────────────────────┘
                   │
                   ▼
┌────────────────────────────────────┐
│            确定剪枝结构            │
│     复制原始权重，不合并 LoRA      │
└────────────────────────────────────┘
                   │
                   ▼
┌────────────────────────────────────┐
│          阶段二：恢复训练          │
│         更新固定结构的学生         │
└────────────────────────────────────┘
                   │
                   ▼
┌────────────────────────────────────┐
│            导出轻量 VAE            │
│      推理无教师、门控、判别器      │
└────────────────────────────────────┘
```

搜索思想参考 [TinyFusion](https://github.com/VainF/TinyFusion/blob/main/prune_by_learning.py)。导出时删除门控，**不合并搜索 LoRA**。编码器、解码器分别搜索和恢复，不是联合训练。

## 2. 阶段一：结构约束剪枝

```text
解码器：按组选择完整 Transformer 块

┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│      原版 36 块      │    │     每组 3 选 1      │    │      导出 12 块      │
│    连续分成 12 组    │───▶│   门控 + 临时 LoRA   │───▶│   移除门控与 LoRA    │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘

编码器：选择残差主分支，保留形状变换骨架

┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│   原版 12 个主分支   │    │    全局保留 3 个     │    │   导出三分支编码器   │
│  每个主分支两层卷积  │───▶│   门控 + 临时 LoRA   │───▶│   旁路与下采样保留   │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘

搜索训练（编码器的像素预测需经过冻结的原版解码器）：

┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│    门控模型的预测    │    │       L_search       │    │       反向更新       │
│   后验 / 重建视频    │───▶│       任务损失       │───▶│   门控 + 临时 LoRA   │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘
```

两种结构共享门控搜索原则，但旁路不同：

$$
H_{\mathrm{out}}=mB(H)+(1-m)H
\qquad \text{（Transformer 完整块）}
$$

$$
x_{\mathrm{out}}=P(x)+mF(x)
\qquad \text{（卷积残差主分支）}
$$

其中 $m\in\{0,1\}$，用直通 Gumbel 门控传梯度；$P$ 是必须保留的恒等或投影旁路。编码器卷积数从 34 降至 16，而不是整个网络只剩三分之一。搜索仍计算所有候选，导出后才真正加速。

搜索损失：

$$
\mathcal L_{\mathrm{search}}^D
=\mathcal L_{\mathrm{rec}}+0.05\mathcal L_{\mathrm{perc}},
\qquad
\mathcal L_{\mathrm{search}}^E
=\mathcal L_{\mathrm{post}}+\mathcal L_{\mathrm{rec}}
+0.05\mathcal L_{\mathrm{perc}}.
$$

## 3. 阶段二：解码器蒸馏

```text
┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│      教师潜变量      │    │      学生解码器      │    │       学生重建       │
│         z_T          │───▶│    12 层，可训练     │───▶│         Y_S          │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘
                                                                    │
                                                                    │
                                                                    ▼
┌──────────────────────┐                                ┌──────────────────────┐
│    对齐的原始视频    │                                │      主像素监督      │
│          X           │───────────────────────────────▶│  重建 + LPIPS + GAN  │
└──────────────────────┘                                └──────────────────────┘

中间层监督：两侧使用相同的教师潜变量作为模型输入

┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│     学生第 j 层      │    │       L_feat_D       │    │     教师第 3j 层     │
│       视频特征       │───▶│       直接 MSE       │◀───│  视频特征，停止梯度  │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘
```

主重建监督完整学生；辅助路径见第 5 节。中间特征只对齐视频 token：

$$
\mathcal L_{\mathrm{feat}}^D
=\frac{1}{12}\sum_{j=1}^{12}
\operatorname{MSE}\!\left(H_j^S,\operatorname{sg}(H_{3j}^T)\right).
$$

学生第 $j$ 层对齐教师第 $3j$ 层的输出，让一个学生块恢复原来三个块的作用。这里是直接 FP32 MSE，不做特征归一化。

## 4. 阶段二：编码器蒸馏

```text
┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│       原始视频       │    │      学生编码器      │    │      学生潜变量      │
│          X           │───▶│   三主分支，可训练   │───▶│  后验均值 + 归一化   │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘
            │                                                       │
            │                                                       │
            ▼                                                       ▼
┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│      主像素监督      │    │       学生重建       │    │    原版完整解码器    │
│  重建 + LPIPS + GAN  │◀───│         Y_S          │◀───│  冻结，保留输入梯度  │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘

后验与特征监督：教师目标均由同一原视频计算

┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│       学生后验       │    │        L_post        │    │       教师后验       │
│     均值与标准差     │───▶│    归一化后验误差    │◀───│       停止梯度       │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘

┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│     学生阶段特征     │    │       L_feat_E       │    │     教师阶段特征     │
│       六个阶段       │───▶│       直接 MSE       │◀───│       停止梯度       │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘
```

只更新学生编码器，**不训练解码器**，也不接入剪枝解码器。

$$
\mathcal L_{\mathrm{post}}
=\operatorname{mean}\!\left[
\left(\frac{\mu_S-\mu_T}{s_z}\right)^2
+\left(\frac{\sigma_S-\sigma_T}{s_z}\right)^2
\right],
\qquad
\mathcal L_{\mathrm{feat}}^E
=\frac{1}{6}\sum_{j=0}^{5}\operatorname{MSE}(F_j^S,\operatorname{sg}(F_j^T)).
$$

$\mu,\sigma$ 是后验均值和标准差，$s_z$ 是原版潜变量标准差；教师目标均停止梯度。后验损失约束潜变量兼容性，像素损失约束实际重建效果。

## 5. 辅助分支：用教师后缀检查学生中间特征

```text
┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│       学生前缀       │    │     学生中间特征     │    │    主路径后续计算    │
│        可训练        │───▶│      H_S / F_S       │───▶│      学生后缀等      │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘
                                        │                           │
                                        │                           │
                                        ▼                           ▼
                            ┌──────────────────────┐    ┌──────────────────────┐
                            │   教师后缀重建路径   │    │       主 loss        │
                            │  冻结，保留输入梯度  │    │     监督完整学生     │
                            └──────────────────────┘    └──────────────────────┘
                                        │
                                        │
                                        ▼
                            ┌──────────────────────┐
                            │       辅助重建       │
                            │        Y_aux         │
                            └──────────────────────┘
                                        │
                                        │
                                        ▼
┌──────────────────────┐    ┌──────────────────────┐
│     完整教师重建     │    │        L_aux         │
│    Y_T，停止梯度     │───▶│     监督学生前缀     │
└──────────────────────┘    └──────────────────────┘
```

主路径在编码器训练时还包含冻结的原版完整解码器。解码器中，教师后缀是剩余 Transformer 块与输出头；编码器中，它是剩余编码阶段、量化层及原版完整解码器。解码器辅助分支使用完整 token 序列，包括辅助 token。

辅助 loss 的三个分量：

```text
┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│       辅助重建       │    │     对齐后的误差     │    │       教师重建       │
│        Y_aux         │───▶│   e = Y_aux - Y_T    │◀───│    Y_T，停止梯度     │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘
                                        │
                                        ▼
            ┌───────────────────────────┼───────────────────────────┐
            │                           │                           │
            ▼                           ▼                           ▼
┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│    Charbonnier(e)    │    │     空间差分误差     │    │   时空混合差分误差   │
│     辅助重建误差     │    │   水平 / 垂直边缘    │    │   边缘随时间的变化   │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘
            │                           │                           │
            ▼                           ▼                           ▼
            └───────────────────────────┼───────────────────────────┘
                                        │
                                        │
                                        ▼
                        ┌──────────────────────────────┐
                        │            L_aux             │
                        │   三项权重：1 / 0.1 / 0.1    │
                        └──────────────────────────────┘
```

令 $e=Y_{\mathrm{aux}}-\operatorname{sg}(Y_T)$：

$$
\mathcal L_{\mathrm{aux}}
=\underbrace{\operatorname{mean}\rho(e)}_{\mathcal L_{\mathrm{aux,rec}}}
+\frac{0.1}{2}\sum_{d\in\{h,w\}}\operatorname{mean}\rho(\Delta_d e)
+\frac{0.1}{2}\sum_{d\in\{h,w\}}\operatorname{mean}\rho(\Delta_d\Delta_t e).
$$

$\rho(u)=\sqrt{u^2+10^{-6}}-10^{-3}$。空间差分检查边缘，时空混合差分检查边缘随时间的变化；都在拼接、裁剪后的像素输出上计算。

反向路径：**辅助 loss → 冻结教师后缀 → 学生中间特征 → 学生前缀**。教师不更新；学生后缀仍由主 loss 训练。这不是 DMD 的假分数网络。

## 6. 最终 loss

| 项目 | 监督内容 |
| --- | --- |
| $\mathcal L_{\mathrm{rec}}$ | 与原视频计算 Charbonnier 重建误差 |
| $\mathcal L_{\mathrm{perc}}$ | 与原视频计算逐帧 VGG-LPIPS |
| $\mathcal L_{\mathrm{feat}}$ | 学生与教师中间特征直接 MSE |
| $\mathcal L_{\mathrm{aux}}$ | 学生特征经过教师后缀，与教师重建对齐 |
| $\mathcal L_{\mathrm{adv}}$ | 条件 3D + 逐帧 2D 判别器提供纹理修正 |
| $\mathcal L_{\mathrm{post}}$ | 编码器额外对齐教师后验 |

对抗项采用受 [Seraena](https://github.com/madebyollin/seraena) 启发的修正目标，不是把判别器 loss 直接加到学生上：

```text
┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│     学生重建裁剪     │    │     独立求导副本     │    │      原视频裁剪      │
│    保留原始计算图    │───▶│     停止原图梯度     │    │    对齐的真实目标    │
└──────────────────────┘    └──────────────────────┘    └──────────────────────┘
            │                           │                           │
            │                           │                           │
            │                           ▼                           │
            │               ┌──────────────────────┐                │
            │               │     条件 3D + 2D     │                ▼
            │               │  判别器多层输出差异  │◀───────────────┘
            │               └──────────────────────┘
            │                           │
            │                           │
            │                           ▼
            │               ┌──────────────────────┐
            │               │      输入负梯度      │
            │               │  归一化、截断、渐入  │
            │               └──────────────────────┘
            │                           │
            │                           │
            ▼                           ▼
┌──────────────────────┐    ┌──────────────────────┐
│     L_adv = MSE      │    │       修正目标       │
│     反向更新学生     │◀───│  sg(副本 + 修正量)   │
└──────────────────────┘    └──────────────────────┘
```

判别条件来自停止梯度的教师潜变量。判别器独立训练；构造修正目标不向学生传播二阶梯度。

$$
\mathcal L_D
=\lambda_{\mathrm{rec}}\mathcal L_{\mathrm{rec}}
+\lambda_{\mathrm{perc}}\mathcal L_{\mathrm{perc}}
+\lambda_{\mathrm{feat}}\mathcal L_{\mathrm{feat}}^D
+\lambda_{\mathrm{aux}}\mathcal L_{\mathrm{aux}}^D
+\lambda_{\mathrm{adv}}\mathcal L_{\mathrm{adv}}.
$$

编码器采用相同组成，但使用编码器特征与辅助路径，并额外加入 $\mathcal L_{\mathrm{post}}$，权重为 1。

恢复共 3000 次更新：前 600 次以重建、LPIPS、特征 MSE 为主；之后加入辅助与对抗监督。每 100 次保存 checkpoint 和重建预览。监督区域先按原版时空 tile 融合再计算 loss，不是直接拿未融合 tile 与完整视频比较。

## 7. 已测速度与显存

单张 H200，124 帧、768×1344，tile 256、最小重叠 64；推理模式，预热 2 次、测量 5 次。显存为峰值已分配显存。

| 模块 | 版本 | 时间／秒 | 显存／GiB |
| --- | --- | ---: | ---: |
| 解码器 | 原版 36 层，部署实现 | 6.207 | 8.859 |
| 解码器 | 原版 36 层，与学生相同实现 | 7.063 | 13.366 |
| 解码器 | 剪枝 12 层 | 2.389 | 7.362 |
| 编码器 | 原版 12 个主分支 | 11.342 | 5.572 |
| 编码器 | 随机保留 3 个主分支 | 3.152 | 4.362 |

解码器：相对部署原版加速 **2.60 倍**；同实现对比加速 **2.96 倍**、峰值显存降低 **44.9%**，主要来自权重减少。部署原版与同实现基线的精度策略不同。

编码器：本次随机三分支加速 **3.60 倍**、峰值显存降低 **21.7%**。它不是搜索恢复后的最终模型；不同分支组合成本不同。

---

通用的是“合法旁路 + 约束门控搜索 + 固定结构恢复”，不是对所有网络使用同一种删层规则。推理仅保留学生，潜变量接口与原版一致。
