# Gradio Deployment Guide

The Gradio application is maintained in the separate [Gradio-Lightx2v repository](https://github.com/ModelTC/Gradio-Lightx2v). Installation, startup commands, supported models, and interface documentation are available there.

LightX2V provides the inference engine; its former `app/` directory has been removed. Installing LightX2V alone does not install the Gradio application.
